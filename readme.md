# ✈️ 飞行学员执照理论考试刷题网页 v1.5

一个专为飞行学员准备的理论考试刷题前端网页应用，支持私照、商照、仪表等级题库。

------

## 🌟 版本 1.5 新特性

- 🏗️ **重构数据结构** - 将原js脚本分为多个模块，代码结构更清晰
- 📊 **增强进度显示** - 新增整体进度管理功能，可视化学习进度
- 🔄 **智能进度同步** - 进度统一保存到index.json中，跨章节同步
- 🐛 **修复关键问题** - 修复没有做完题目就刷新会导致剩余题目显示出错的bug
- 📁 **优化导入导出** - 修复了导出错题和导入错题功能
- 💬 **新增提示系统** - 增加右上角消息提示框，操作反馈更直观
- 🔄 **进度管理** - 可以初始化全部题库进度，一键重置
- 🎨 **界面优化** - 更新当前做题数据显示，正确率带有动画效果

------

## 🚀 核心功能

### 📚 题库管理

- **三大执照题库** - 私照(2307题)、商照(3707题)、仪表(2900题)
- **章节细分** - 每个执照按知识点分章节练习
- **离线使用** - 纯前端实现，无需服务器支持

### 📊 学习进度

- **实时统计** - 显示正确/已做题目数量和正确率
- **环形进度** - 可视化正确率进度条，颜色随分数变化
- **整体进度** - 查看所有题库的完成情况和统计信息
- **本地保存** - 自动保存答题进度到浏览器本地存储

### 🎯 答题体验

- **智能导航** - 题目导航圆圈显示答题状态（正确/错误/未答）
- **自动跳转** - 可选答对后自动跳转到下一题
- **解析展示** - 答题后立即显示题目解析和相关图片
- **错题复习** - 专门查看错题模式，针对性强化练习

### 🔧 实用工具

- **进度重置** - 可重置当前章节或全部题库进度
- **错题导出** - 导出错题为JSON文件，便于复习
- **错题导入** - 导入之前导出的错题集
- **更新日志** - 查看版本更新历史和新功能说明

------

## ⚙️ 技术架构

| 模块               | 功能                              | 文件       |
| :----------------- | :-------------------------------- | :--------- |
| **main.js**        | 核心逻辑，题库导入/导出，答题处理 | 主程序模块 |
| **dataManager.js** | 数据管理，进度保存，题库状态      | 数据管理层 |
| **uiManager.js**   | 界面渲染，题目显示，导航更新      | 视图控制层 |
| **utils.js**       | 工具函数，消息提示，模态框        | 工具服务层 |

**前端技术栈**: HTML5 + CSS3 + 原生JavaScript
**数据存储**: localStorage + JSON文件
**部署方式**: GitHub Pages / 本地静态服务器

## 💾 数据管理

### 进度保存

- ✅ **自动保存** - 答题进度自动保存到浏览器本地存储
- ✅ **跨设备** - 支持导出/导入进度文件
- ✅ **多维度** - 记录章节进度、正确率、答题状态

### 文件格式

- **题库文件**: JSON格式，包含题目、选项、答案、解析
- **进度文件**: JSON格式，记录用户答题状态和统计信息
- **错题文件**: JSON格式，导出需要重点复习的题目

## 🎮 使用指南

### 开始刷题

1. 选择执照类型（私照/商照/仪表）
2. 选择具体章节
3. 点击"导入题库"开始练习

### 功能操作

- **答题**: 点击选项选择答案，自动显示解析
- **导航**: 点击题目编号圆圈快速跳转
- **统计**: 实时查看正确率和完成进度
- **复习**: 完成所有题目后进入错题复习模式

### 进度管理

- **重置进度**: 清空当前章节答题记录
- **导出错题**: 将错题导出为JSON文件
- **导入错题**: 加载之前导出的错题集
- **整体进度**: 查看所有题库的学习统计
